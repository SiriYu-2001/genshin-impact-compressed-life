# 压缩人生 · Genshin Impact

《原神》任务剧情的分层可视化档案，按任务类型组织，并以
`scene → chapter → section` 展示剧情脉络、动机、结果和来源步骤。

本仓库仅包含生成后的静态网页，不包含原始剧情抓取数据、模型凭据、
运行日志或中间工作目录。

## 数据规模

- 1,714 个 scene
- 魔神、传说、活动、世界、委托及其他任务分类
- 每个 scene 按需加载独立 JSON

## 本地预览

```bash
python3 -m http.server 8000
```

打开 <http://127.0.0.1:8000/>。
